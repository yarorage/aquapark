# аквапарк — официальный сайт

Сайт музыкальной группы **«аквапарк»** (Москва, инди-рок / инди-поп).

Гитарный инди-поп про радости, горести, взросление и любовь. Светлая меланхолия и лёгкая панк-романтика.

## Технологии

Чистые HTML, CSS и JavaScript — без сборщиков и зависимостей. Анимированный водный фон на Canvas, адаптивная вёрстка, лайтбокс для галереи.

## Как открыть

Просто откройте `index.html` в браузере или разместите папку на любом статическом хостинге (GitHub Pages, Netlify и т.д.).
